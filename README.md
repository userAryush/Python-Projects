# Python-Projects
<p>Here i have posted some simple python projects that i have done during learning python.</p>
This repository contains a collection of beginner to intermediate Python projects that demonstrate fundamental concepts such as file handling, loops, conditionals, functions, dictionaries, and user input.

## Projects Included

- **CafeMenu.py** – Menu-based program simulating a café ordering system.
- **RockPaperScissors.py** – Classic Rock-Paper-Scissors game.
- **Timedmath.py** – Time-based math quiz.
- **Xmatrix.py** – Matrix-based logic and pattern printing.
- **atm.py** – Simple ATM simulation.
- **currencyconverter.py** – Currency conversion using dictionary data.
- **kbc.py** – Quiz game inspired by “Kaun Banega Crorepati”.
- **library.py** – Basic library management system using dictionaries.
- **passwordmanager.py** – Secure password storage using basic encryption logic.
- **randomnumberguess.py** – Number guessing game.
- **timeGreetings.py** – Time-based greeting generator.
- **todo.py** – Command-line to-do list manager.
- **word_freq_counter.py** – Word frequency counter from text files.
